# Boone website

The one-page site for Boone, the visual schedule app. It will live at getboone.app.

- `index.html`: the page. `site.css`: the look. `site.js`: the try-it card stack, Boone's night shift, and the email sign-up.
- `img/`: pictures (Boone on the dock, Kawaii card pictures from Flaticon, the Harbor Nights sticker page).
- `fonts/`: Fraunces, Atkinson Hyperlegible and Courier Prime, served from here so visitors' browsers never call Google.
- Email sign-ups go to Boone's Kit form (10005040).
- Help, privacy and terms pages live with the app on EAS Hosting.

Hosted free on GitHub Pages from the `main` branch.
